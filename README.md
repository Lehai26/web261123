e.target와 this의 차이
- e.target: 실제로 클릭한 요소를 의미한다. 하트 버튼을 클릭하면 하트 버튼이 되고, 포스터 이미지를 클릭하면 이미지가 된다.
- this: 일반 함수 function(e)에서는 이벤트가 등록된 요소를 의미한다. 이번 과제에서는 .board에 이벤트를 등록했기 때문에 this는 .board가 된다.
- 화살표 함수 (e) => {}에서는 this가 Window로 나타난다.

- renderCards()가 실행될 때 기존 카드를 삭제하고 새로운 카드를 만든다. 이때 기존 하트 버튼도 함께 삭제되기 때문에 버튼에 직접 등록한 이벤트도 사라진다.

이 문제를 해결하기 위해 각 버튼에 이벤트를 등록하는 대신, 모든 카드를 감싸는 .board에 이벤트를 하나만 등록한다.

버튼을 클릭하면 이벤트가 바깥쪽으로 전달되므로 e.target.classList.contains("like")를 사용해서 하트 버튼을 클릭했는지 확인할 수 있다.
